🌌 About The Project

NEON TO-DO is a simple and stylish productivity application designed to help users manage their daily tasks.

It combines a modern dark interface with glowing purple accents, interactive task controls and automatic browser storage.

✨ Features

- ➕ Add Tasks — Create tasks instantly.
- ✅ Complete Tasks — Mark tasks as finished.
- ✏️ Edit Tasks — Update existing tasks.
- 🗑️ Delete Tasks — Remove unwanted tasks.
- 📊 Live Statistics — Track total, completed and pending tasks.
- 🧹 Clear Completed — Remove all completed tasks at once.
- 💾 Local Storage — Keep tasks saved in your browser.
- 📱 Responsive Design — Comfortable layout on mobile and desktop.
- ⚡ Keyboard Support — Press Enter to add a task.

🎨 Design Highlights

- Dark futuristic background
- Neon-purple glow effects
- Modern task cards
- Clean typography
- Interactive buttons
- Minimal and responsive layout

🚀 Getting Started

Run Locally

1. Clone this repository:
   
   git clone https://github.com/subha445/Todo---app.git

2. Open the project folder.

3. Open "index.html" in your browser.

That's it! Your To-Do App is ready.

📖 How To Use

1. Enter your task in the input field.
2. Press Add +.
3. Tap a task to mark it completed.
4. Use Edit to change a task.
5. Use X to delete a task.
6. Select Clear Completed Tasks to clean up your list.
